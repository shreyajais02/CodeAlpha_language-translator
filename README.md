# 🌍 AI Language Translator

A simple and modern language translation web application built using Python, Streamlit, and Google Translator.

## Features
- 🌐 Translate text between multiple languages
- 🔄 Swap source and target languages
- 🎨 Modern dark maroon UI
- ⚡ Fast translations
- 🌍 Supports multiple languages including:
  - English
  - Hindi
  - Punjabi
  - Bengali
  - Sanskrit
  - French
  - Spanish
  - German

## Technologies Used
- Python
- Streamlit
- deep-translator

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
